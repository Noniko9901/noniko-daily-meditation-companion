Daily Meditation companion for Narcotics Anonymous members with language support.

== Description ==

Noniko Daily Meditation Companion displays the daily meditation from Narcotics Anonymous (NA).

The plugin automatically displays the meditation matching the current date using a WordPress shortcode.

The plugin includes:
- daily meditation display,
- Polish language support,
- multilingual system ready for additional languages,
- automatic database installation,
- simple WordPress integration.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/noniko-daily-meditation-companion` directory.
2. Activate the plugin through the WordPress Plugins screen.
3. The plugin will automatically create the required database tables.
4. Add the shortcode to any page or post.

== Frequently Asked Questions ==

= How do I display today's meditation? =

Add the meditation shortcode provided in the plugin administration panel.

= Does the plugin support multiple languages? =

Yes. The plugin includes a language system that allows adding additional language versions.

= Does the plugin create database tables automatically? =

Yes. Required tables are created automatically during plugin activation.
