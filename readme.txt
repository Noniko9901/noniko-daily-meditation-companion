Daily Meditations from Narcotics Anonymous in Polish.

== Description ==

Noniko Daily Meditation Companion displays the daily meditation for Narcotics Anonymous members in Polish using a shortcode.

== Installation ==

1. Upload the plugin.
2. Activate it.
3. Use the shortcode.

== Frequently Asked Questions ==

= How do I display today's meditation? =

Use the shortcode.
